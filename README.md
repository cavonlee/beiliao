# 备料清单（3 天自动下线）

测试架 4 块板（O3605V20 主板 / O3608 USB-C 通道 / O3609 电池通道 / O3611 诱骗器）
按 2 套合并的物料清单，勾选要买的料 → 导出 → 复制，交给采购。

- 页面：`index.html`（单文件，无外部依赖；字体走 Google Fonts，无网也能看，只是字形退到系统字体）
- **自动下线**：`.github/workflows/expire.yml` 每天跑一次，仓库创建满 3 天后把页面替换成「已过期」并删除 Pages，与本地电脑是否开机无关（跑在 GitHub 上）
- 数据来自各板 `生产文件\*bom.csv`，由 `beiliao` 技能的 `gen_beiliao.py` 生成；DNP 剔除、按「数值 + 封装」跨板聚合
